## Featured Project

### 🔍 [Crypto AML Risk Detector](https://github.com/shlokdinesharora/crypto-aml-risk-detector)

A graph-based anti-money-laundering system for detecting suspicious Bitcoin transactions using the Elliptic transaction dataset.

- Represents Bitcoin transactions as graph nodes and payment flows as directed edges
- Uses a three-layer Graph Convolutional Network built with PyTorch Geometric
- Uses class-weighted training with stratified train, validation, and held-out test splits
- Includes an interactive Gradio dashboard for transaction risk prediction
- Provides suspicion scoring, risk-tier assignment, and two-hop neighborhood exploration
- Organized into separate modules for preprocessing, training, evaluation, inference, configuration, and UI

#### Model Performance

| Metric | Score |
|---|---:|
| Test Accuracy | 94.32% |
| Illicit-Class F1 Score | 75.48% |
| ROC-AUC | 97.18% |

**Tech stack:** Python, PyTorch Geometric, Scikit-learn, Pandas, NumPy, Gradio

> This project began as a prototype developed during HackNite, organized by IBM and Manipal Institute of Technology, and was later expanded into a reproducible machine-learning application.
